EYEbrary User Manual

EYEbrary lets you build a reusable clinical library and assemble it into clean, patient-facing PDF reports in seconds. The app has three tabs — New Report, Library, and Settings — described below.

1. Building a Report

The New Report tab — build and export a patient report

Basic flow

  • Open the New Report tab.
  • Tap entries from your library to add them to the report.
  • Reorder, edit, or remove entries as needed.
  • Add an optional patient name and exam date.
  • Tap Export PDF to generate and share the report.

Add custom entries on the fly

  • Tap the + button to add a free-typed entry to the current report.
  • Filter and sort the entry picker by category to find items quickly.

Choose a letterhead and font size

  • Next to Export PDF, pick a letterhead — "Blank (Built-in)" or any letterhead you've imported (see section 9).
  • Use the text-size menu to set the report font: Standard, Large, or Extra large — handy for low-vision patients.

Export & share

  • Export PDF produces a polished, letterhead-branded PDF and opens the system share sheet, so you can print it, save it to Files, email it, or AirDrop it.
Only entries marked visible appear in the New Report picker. Hide reference-only entries from the Library (section 4) to keep the picker focused.

2. Editing Entries in a Report

Expanded content editing mode
  • Tap an entry in the report to edit its text.
  • Tap Expand Content for a larger, full-screen editor.
  • The active entry is highlighted with a blue border while expanded.
  • Editing an entry in a report does not change your saved library entry — reports are a working copy.
Use Expand Content for long or detailed edits — it is much more comfortable than inline editing.

3. Collapsed vs Expanded View

Collapsed view gives a clean overview of the report
  • Collapse entries for a quick overview of the whole report.
  • Expand an entry only when you need to edit it.

4. The Library

The Library tab is where you manage your reusable content.

  • Search across entry titles and body text.
  • Filter by category.
  • Sort: Manual (drag to reorder), A–Z, Z–A, Newest updated, or Oldest updated.
  • Mark entries as favorites to keep them at the top.
  • Toggle whether an entry is visible in New Report.
  • Swipe to delete; drag to reorder when in Manual sort.

5. Editing a Single Entry

  • Edit the entry's title and rich-text content.
  • Assign a category.
  • Toggle visibility in New Report.
  • Mark as a favorite.
The formatting "magic wand" cleans up spacing and tidies bulleted and numbered lists so they export neatly.

6. Batch Select (Bulk Actions)

  • Select multiple entries at once — selection persists as you search and re-sort.
  • Apply bulk actions:
    • Recategorize
    • Delete
    • Export the selected entries as a single file

7. Categories

  • Categories are global — shared across all of your libraries.
  • Create, rename, reorder, and delete categories.
  • Deleting a category reassigns its entries to General.
  • General is the default category and cannot be renamed or deleted.

8. Libraries

  • Keep multiple independent libraries and switch the active one instantly.
  • Create, rename, delete, and reorder libraries.
  • Export any library on its own to share or back up.

9. Importing & Exporting Libraries

EYEbrary imports and exports .json files and .eyebrarylib library packages. When importing, choose how the content is added:

  • Merge → adds new entries and updates existing ones.
  • Replace → overwrites the active library.
  • New Library → creates a separate library from the file.
Turn off "Normalize text on import" if the formatting in your file is already exactly how you want it.

10. Letterheads & the Safe Zone Editor

In Settings → Letterhead you can brand your reports with your own stationery.

  • Tap Import Letterhead PDF to add a letterhead.
  • Tap a letterhead to make it the active one (shown by the filled circle).
  • Swipe a letterhead to delete it.

Setting the safe zone

Tap the crop icon on a letterhead to open the Safe Zone Editor. The safe zone tells EYEbrary where report text may go so it never overlaps your logo, header, or footer.

  • Drag the blue rectangle — or its handles — to set the area where report content prints.
  • Drag the orange "Page X of Y" pin to position the page number.
  • Reset to Default restores the standard margins.
  • Tap Save to store the safe zone for that letterhead.
Each letterhead keeps its own safe zone, so you can switch between differently designed letterheads without re-adjusting anything.

11. Backup & Restore

In Settings → Backup you can save or restore your entire setup.

  • Back Up Entire App saves all your libraries, categories, and letterheads (including their safe-zone settings) into a single file named "EYEbrary Backup YYYY-MM-DD". Save it to Files, iCloud Drive, or wherever you keep backups.
  • Restore from App Backup loads a backup file and replaces all current libraries, categories, and letterheads. A confirmation shows what the backup contains before anything changes.
Report history and any in-progress report are not included in a backup — it is meant for your reusable content and settings, not patient reports. Restoring cannot be undone, so keep a current backup before restoring an older one.

12. Settings Overview

  • Manage libraries, categories, and letterheads.
  • Back up and restore the whole app.
  • Open the Quick Start Guide and About screen.
  • Reset App to Factory Defaults returns EYEbrary to its bundled starter library.

13. Undo

  • Structural changes — creating, renaming, deleting, or reordering libraries, categories, and entries, and import merge/replace — can be undone.
  • On a keyboard, use ⌘Z to undo and ⇧⌘Z to redo.

14. Privacy

  • Patient names are optional.
  • Patient names are not stored in autosaved drafts.
  • Report history keeps no patient-identifying data.
  • A restored draft never brings back a patient name.

15. Tips

  • Use Expand Content for comfortable, reliable editing.
  • Use Batch Select for cleanup and reorganizing.
  • Use favorites and categories to speed up your workflow.
  • Set a safe zone for each letterhead once, and reports always fit your branding.
  • Back up the app before importing or restoring large changes.

16. Disclaimer

EYEbrary is a report-generation tool. All content must be reviewed by the practitioner before sharing with patients.
